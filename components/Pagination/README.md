# Pagination

Stránkování pod tabulkou s rozsahem záznamů a ± 2 stránkami.

**Kdy:** pod každou stránkovanou tabulkou.

**Dodáváš:** `page`, `totalPages`, `total`, `pageSize`, `noun` (genitiv: „zakázek“, „úkolů“) a `onPage`.

**Pravidla:** aktuální stránka je černá. První a poslední jsou vždy dostupné, mezera „…“. Stránka patří do URL.
