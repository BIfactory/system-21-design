# EmptyState

Prázdný stav s ikonou, vysvětlením a další akcí.

**Kdy:** seznam nebo sekce bez dat. Pro prázdný výsledek filtru stačí text `DataTable.empty`.

**Dodáváš:** `icon`, `title`, `description` a `action` (obvykle `Button primary`).

**Pravidla:** čárkovaný obrys, ikona na `primary-soft`. Text řekne, proč je prázdno a co dál.

_Ručně přepsáno ze zdroje: components/intranet/empty-state.tsx (hulinl/polepim-manager@19de5c8), přebarveno na System 21._
