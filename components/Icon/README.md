# Icon

Sada čárových ikon 24×24 ve stylu Lucide, tah 2 px, barva currentColor.

**Kdy:** menu (18 px), tlačítka (16 px, v `sm` 14 px), prázdné stavy (28 px).

**Dodáváš:** `name` (viz `Icon.names`), `size`, `strokeWidth` a `title` (jen když ikona nese význam sama).

**Pravidla:** ikona bez textu musí mít `aria-label` na tlačítku. Chybějící ikony doplň ze sady Lucide ve stejném stylu. Emoji nepoužívej.

_Ručně přepsáno ze zdroje: components/layout/sidebar.tsx (ICONS), components/intranet/icons.tsx (hulinl/polepim-manager@19de5c8), přebarveno na System 21._
