# Input

Textové a číselné pole ve standardní výšce 36 px.

**Kdy:** jakýkoli jednořádkový vstup. Ve formuláři ho vždy obal do `Field`.

**Dodáváš:** atributy `<input>` a `invalid` (červený obrys).

**Pravidla:** placeholder je kurzívou v `ink-subtle` a slouží jako příklad, ne jako popisek. U číselných polí zakaž změnu kolečkem myši (v originále `NumberInputWheelGuard`).
