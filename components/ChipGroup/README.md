# ChipGroup

Filtrovací čipy pro přepínání skupin seznamu.

**Kdy:** nad `FilterBar` pro hlavní skupiny seznamu (Sales pipeline / Vše / Hotové).

**Dodáváš:** `items [{value, label, count?}]`, `value`, `onChange`.

**Pravidla:** aktivní čip je černý (`black`/`white`), ostatní bílé s obrysem. Výběr patří do URL. Pro 2 až 5 skupin, víc řeš selectem.
