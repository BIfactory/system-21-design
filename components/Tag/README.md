# Tag

Malý příznak vedle názvu pro rizika a doplňující informace.

**Kdy:** „Po termínu“, „Záporná marže“, „Fakturováno“, „Nové“, tedy vedle názvu v prvním sloupci tabulky nebo v titulku karty.

**Dodáváš:** `tone` (`neutral` | `success` | `warning` | `danger` | `accent`) a `children`.

**Pravidla:** písmo `micro` (10 px tučně), `radius-full`. `accent` (žlutá) jen pro „Nové“. Na řádek nejvýš dva tagy.
