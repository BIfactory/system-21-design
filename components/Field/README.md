# Field

Obal pole s mono popiskem nahoře a nápovědou nebo chybou dole.

**Kdy:** každé pole ve formuláři a modalu.

**Dodáváš:** `label`, `children` (`Input`, `Select`…), volitelně `hint` nebo `error`.

**Pravidla:** popisek je v mono verzálkách (`label`), chyba nahrazuje nápovědu a je v `danger-text`. Pole řaď pod sebe, na desktopu nejvýš 3 vedle sebe.

_Ručně přepsáno ze zdroje: vzor z formulářů aplikace (article-form, training-form, modaly) (hulinl/polepim-manager@19de5c8), přebarveno na System 21._
