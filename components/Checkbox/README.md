# Checkbox

Zaškrtávací přepínač v rámečku s volitelným počtem.

**Kdy:** přepínače filtru („Zobrazit neaktivní“, „Jen moje“) a ano/ne volby ve formulářích.

**Dodáváš:** `label`, volitelně `count` a atributy `<input type="checkbox">`.

**Pravidla:** ve `FilterBar` je vpravo. Zaškrtnutí je v barvě `primary`.
