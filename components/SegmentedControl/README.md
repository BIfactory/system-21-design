# SegmentedControl

Přepínač období nebo režimu zobrazení v jednom rámečku.

**Kdy:** Denní / Týdenní / Měsíční na dashboardech, přepnutí seskupení (podle lidí / podle zakázek).

**Dodáváš:** `items [{value, label, icon?}]`, `value`, `onChange`.

**Pravidla:** aktivní segment je `primary` s `on-primary`. Popisky jsou bez emoji (originál je měl, System 21 je vypouští). Hodnota patří do URL.

_Ručně přepsáno ze zdroje: components/charts/period-toggle.tsx (hulinl/polepim-manager@19de5c8), přebarveno na System 21._
