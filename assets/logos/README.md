# Logos

Demo značka BIfactory. U zákaznických implementací se soubory v této skupině vyměňují.

- `bifactory-logo.png`: primární logotyp (wordmark „BI factory“ + symbol databáze), 500×500, černý text a zelený symbol `#43C466`. Jen na světlé plochy (`surface`, `paper`), například na přihlašovací obrazovku a do PDF výstupů. Minimální výška 32 px.
- `bifactory-mark.png`: samostatný symbol databáze v `primary` zelené, 191×206. Patří do hlavičky `Sidebar` (36 px) na `sidebar-bg`, na favicon a na ikonu aplikace.

Logo nedeformuj, nenatáčej, nepřebarvuj a nepřidávej mu efekty. Ochranná zóna = výška symbolu databáze.
